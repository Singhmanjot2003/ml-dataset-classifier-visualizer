This project is an interactive machine learning web application built using Streamlit that allows users to explore and compare different classification algorithms on popular datasets. The app provides a user-friendly interface where users can select datasets such as Iris, Wine, and Breast Cancer from Scikit-learn and choose classifiers like K-Nearest Neighbors (KNN), Support Vector Machine (SVM), and Random Forest. It dynamically adjusts model parameters through sidebar controls, enabling real-time experimentation. The selected model is trained on the dataset using a train-test split, and its performance is evaluated using accuracy metrics. Additionally, the application visualizes the dataset by reducing its dimensions using Principal Component Analysis and plotting it in a 2D space for better understanding. Overall, this project demonstrates practical implementation of machine learning concepts, model comparison, and data visualization in an interactive environment.
